# Coastal Signal Lab — sample research showcase

A polished, dependency-free static website for presenting a research project, reports, figures, and a small dataset. The content is fictional demonstration material and is ready to replace with a real project.

## What is included

- Responsive one-page research showcase
- Two readable, print-friendly HTML reports
- Three original SVG data figures with an accessible lightbox
- A downloadable sample CSV dataset
- GitHub Pages-ready structure with no build step

## Preview locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

## Customize

1. Replace the project title and summary in `index.html`.
2. Update findings, dates, and methods with your real research content.
3. Replace the SVG files in `assets/` with project images while keeping the filenames, or update the image paths.
4. Replace the demonstration CSV in `data/`.
5. Add or revise reports in `reports/`.

## Publishing

The repository is ready for GitHub Pages from the `main` branch and repository root.
